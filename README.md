# Lumen — The Best Free Images

A scroll-driven landing page and image gallery for Lumen, a free service for high-quality photos.

- Loader, pinned scroll scenes, parallax and text reveals built with GSAP + ScrollTrigger and Lenis smooth scrolling.
- Working gallery: themes, search, favorites (saved in the browser), lightbox with keyboard and swipe navigation.
- Photo data and author credits come from the [Lorem Picsum](https://picsum.photos) API (images by Unsplash photographers).

Static site — open `index.html` or serve the folder with any static server.
